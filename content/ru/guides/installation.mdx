## Требования

- Node.js `^20.19.0 || >=22.12.0`
- React `^19.0.0` и `react-dom` `^19.0.0` как **peer**-зависимости — их ставите вы сами, пакет React
  в себя не тянет.
- Сборщик, понимающий ESM. Пакет — **только ESM**: сборки под CommonJS нет, резолвинг в стиле
  Node 10 не поддерживается. Потребителю на CommonJS придётся использовать динамический `import()`.

## Единственный файл стилей

Компоненты не несут инлайновых стилей и ничего не вставляют в рантайме. Импортируйте файл стилей
один раз, где-нибудь рядом с точкой входа приложения:

```tsx
import { Button } from '@kreobuddha/ui';
import '@kreobuddha/ui/styles.css';

export const Example = () => (
  <Button variant="filled" onClick={save}>
    Finish setup
  </Button>
);
```

`@kreobuddha/ui/styles.css` — это весь поддерживаемый CSS: слой токенов плюс стили всех компонентов.
Отдельных файлов стилей на компонент нет, настраивать в сборке тоже нечего.

## Граница пакета

| Экспорт          | Что внутри                                       |
| ---------------- | ------------------------------------------------ |
| `.`              | именованные React-компоненты и их публичные типы |
| `./styles.css`   | весь поддерживаемый CSS                          |
| `./package.json` | манифест                                         |

Больше импортировать нечего. Глубокие пути внутрь `dist` частью API не являются и сломаются.

## Шрифты

Шрифт лежит внутри пакета, внешних запросов не делается. Импорта стилей достаточно: Inter едет
в пакете вариативным шрифтом, разбитым на латинский и кириллический файлы по `unicode-range`, так
что страница на латинице никогда не скачает кириллический сабсет. Ни ссылки на CDN добавлять, ни
сетевой зависимости принимать не нужно.

Моноширинного семейства в пакете нет. Цифры, которые должны выстраиваться в колонку, используют
`--kreo-numeric-tabular` — см. [Типографику](../typography/).

## TypeScript

<Details id="ts2882" label="TS2882 на импорте стилей">
  Чтобы импортировать `@kreobuddha/ui/styles.css` из TypeScript, в проекте уже должны быть
  объявлены типы для сайд-эффектных импортов CSS. В проекте на Vite это
  `"types": ["vite/client"]` в `tsconfig.json`. Без этого TypeScript 6 сообщает `TS2882` на
  импорт стилей. Это свойство сборки хоста, а не пакета.
</Details>
